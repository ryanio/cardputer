# Handoff: flint, 2026-08-18

Firmware for the M5Stack Cardputer ADV, in `ryanio/cardputer`, published at
<https://ryanio.github.io/cardputer/>. Named flint as of `51b5262`; Coral is one
of its sources, not the name of the thing.

Read [CLAUDE.md](../../CLAUDE.md) first, then [docs/PLAN.md](../../docs/PLAN.md)
for how the work is split and [docs/API.md](../../docs/API.md) for every
endpoint shape, all of which were probed live rather than remembered.

## The constraint that shapes everything

**No unit has ever been flashed.** Every screenshot in the repo and on the site
came out of the simulator. Compiles is not works, and the Stage 1 flash gate in
PLAN.md has not been run, so three things in the plan are still guesses:
whether there is PSRAM, whether a TLS handshake fits beside the display buffer,
and whether the panel and keyboard behave as the library claims.

Only Ryan can flash. Everything else is verifiable without hardware through the
simulator, which is why it was built.

## Traps found the hard way

Things that cost time this session and are not obvious from the code:

- `PASS_MAX` is a macro in macOS `limits.h`. The desktop build catches
  collisions the device toolchain never mentions, which is a feature.
- SDL's renderer holds a WebGL context whose output never reached the canvas. A
  red test clear proved it. The web build reads the panel framebuffer and paints
  a 2D canvas instead; do not try to "fix" it back.
- The browser build cannot have a second thread without cross origin isolation
  headers that GitHub Pages does not send, so `Panel_sdl::main` is unusable
  there and the panel is pumped from the page's frame loop.
- emsdk needs Python 3.10 or newer; the system python is 3.9. Install with
  `PATH="/opt/homebrew/bin:$PATH" ./emsdk install latest`.
- `gh` resolves to the `upstream` remote, which is M5Stack's repo. Always pass
  `-R ryanio/cardputer`.
- The wasm in `site/sim/` is committed on purpose so the site never depends on
  a toolchain in CI. **Rebuild it with `sim/web/build.sh` after any firmware
  change**, or the site quietly serves the old firmware.
- Font2 draws a backtick as a small raised circle, so on-screen hints about the
  exit key read oddly. Worth spelling out as "esc" instead.
- Two API surfaces needed a CA root nobody would guess: GitHub needs Sectigo,
  Bankr needs Amazon. Both are in the bundle now. Check the chain before adding
  any new host.
