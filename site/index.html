Try it without hardware

The simulator is not a mockup and not a reimplementation. M5GFX ships a desktop panel and knows this board, so the firmware's own view and drawing code runs on your machine through the real graphics library at the real 240x135, with the real fonts. 

git clone https://github.com/ryanio/cardputer
brew install sdl2
pio run -e sim -t exec -a --tour

The tour drives itself and prints what it is pressing, so nothing has to be guessed. Interactively, Escape is the backtick, so it always backs out.

How it behaves

  • Every screen has a way out. The input loop takes the backtick before any view sees it, so no screen can trap you by forgetting to handle a key.
  • No secrets on the device. Every source it reads is public and unauthenticated, including the Bankr agent leaderboard. Nothing needs a key, so there is nothing to leak in a flashed binary and nothing to rotate.
  • WiFi is typed on the unit. Credentials live in NVS rather than the build, so a unit you hand to someone joins their network and does not carry yours.
  • Poll windows are respected. Gas refreshes every 30 seconds because that is what the server does. The daily round is fetched once and then played with the radio off.
  • A score always carries its caveats. Anything showing a Coral score shows what it is not, alongside the Coral name.

The hardware

BoardM5Stack Cardputer ADV (K132-ADV), Stamp-S3A, ESP32-S3FN8, 8MB flash
Screen240x135 ST7789V2. Four lines of large text, or eight small
Keyboard56 keys over a TCA8418, which needs M5Cardputer 1.1.1 or newer
Also on boardBMI270 IMU, ES8311 codec and a 1W speaker, MEMS mic, IR emitter, microSD, 1750mAh
FirmwareArduino under PlatformIO. Serial only, never USB HID
